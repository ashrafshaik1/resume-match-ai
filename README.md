# ResumeMatch AI

An AI-powered resume and job matching system that analyzes resumes against job descriptions and identifies matching skills, missing skills, and overall compatibility.

## 🚀 Live Demo

**Try ResumeMatch AI:**  
https://resume-match-ai-ashraf.streamlit.app

## 📌 Project Status

✅ Completed & Deployed

## ✨ Features

- 📄 Upload resumes in **PDF** or **DOCX** format
- 🔍 Extract text from uploaded resumes
- 🧠 Identify technical skills from resumes
- 💼 Analyze skills required by a job description
- ✅ Identify matching skills
- ❌ Identify missing skills
- 📊 Calculate overall skill compatibility
- 💡 Provide suggestions based on missing skills
- 🎨 Interactive and responsive Streamlit interface
